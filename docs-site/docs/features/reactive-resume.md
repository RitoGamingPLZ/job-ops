title: Reactive Resume (removed)
description: The Reactive Resume integration was removed; JobOps renders resume PDFs locally.
unlisted: true
---

JobOps no longer integrates with Reactive Resume. Resumes are edited in the [co-work resume editor](/docs/next/features/design-resume) and PDFs are rendered locally with Typst or LaTeX.

See [Resume PDF and projects](/docs/next/features/resume-pdf) for the renderer settings and project selection controls.
